# Archivo 47 — Ecos de un mundo dividido

Videojuego educativo web de Historia centrado exclusivamente en **Guerra Fría y descolonización**.

## Concepto
El jugador recorre cuatro salas de un archivo histórico, recupera evidencias y resuelve desafíos de dificultad progresiva. La exploración no es decorativa: cada objeto del escenario activa una evidencia o una mecánica vinculada con la reconstrucción histórica.

## Controles
- WASD / flechas: desplazamiento
- E / Enter: interactuar
- M: abrir expediente de evidencias
- ESC: pausa
- Botón Audio: activar/desactivar música ambiental

## Progresión
1. Mundo bipolar — reconocimiento y relaciones básicas.
2. Crisis y equilibrio — cronología, Berlín y riesgo nuclear.
3. Fin de los imperios — diversidad de procesos de descolonización, Indonesia y persistencia de dependencias.
4. Mesa de síntesis — combinación de evidencias y construcción de un informe histórico.

## Mecánicas
Exploración top-down, asociación, reconstrucción cronológica, análisis de fuentes, selección de evidencias, toma de decisiones, pistas progresivas, tablero integrador y argumentación final.

## Audio
La ambientación es original y se genera mediante Web Audio API en el navegador. No utiliza canciones ni grabaciones protegidas.

## Publicación
Es un proyecto web estático. Para GitHub Pages, subir `index.html` y `README.md` a la raíz del repositorio y activar Pages.

## Nota
El contenido del juego fue construido a partir de los materiales proporcionados para Historia y mantiene como eje Guerra Fría y descolonización.
